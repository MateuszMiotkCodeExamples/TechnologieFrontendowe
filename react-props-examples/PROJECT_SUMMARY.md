## Uruchomienie Projektów

```bash
# Wejdź do katalogu projektu
cd react-props-examples/<numer-projektu>

# Zainstaluj zależności (pierwszy raz)
npm install

# Uruchom serwer deweloperski
npm run dev

# Aplikacja będzie dostępna pod: http://localhost:3000
```
