### Uwaga

Przykład z użycia formik znajdue się pod adresem http://localhost:3000/formik_example

Dodawanie komponentów znajduje się pod adresem http://localhost:3000. Domyślnie używany jest komponent **AddColorForm_with_formik**. W celu zmiany należy użyć innego kompoenentu (AddColorForm, **AddColorForm_Controlled**, **Add_ColorFormControlled2**)
